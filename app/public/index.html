Run the reduced protocol on the systems you choose Select the systems under test and the judge panel, edit the tasks and rubrics, set regenerations and repeat scorings, and run. Judging is blind and order-randomised; every verdict and score is kept; the paired permutation tests, Holm correction and effect sizes follow the paper.

Keys stay in this local process and are never written to disk. Hover over a ? for an explanation.

1. Connection

Fetches the models this key can call, with each model's documented effort settings, from the DAILFT API. Until it is loaded, the model-id suggestions are a fixed fallback and no effort settings are offered in DAILFT mode. No model list loaded.

2. Systems under test (C) Each row is one system. Tick several effort settings for a system and each ticked setting is one condition (E); with two or more ticked, choose the one its comparisons are made at (the first by default); in DAILFT mode the settings appear once the model list is loaded. A DAILFT panel is one system: enter quick-panel:modelA,modelB,modelC (one challenge round, one synthesised answer) or full-panel:modelA,modelB,modelC (the full deliberation loop) as the model id.

3. Judge panel (J) Judges see the task, the rubric and anonymised answers; never system names. Choose judges from different model families; inter-judge agreement is reported with the results (S5).

4. Tasks and rubrics (T) Starter tasks are included so the mechanism runs out of the box; replace them with your own. One rubric criterion per line. The judge marks each MET or UNMET and writes a score line, asked to be the percentage MET; on these tasks that line is the score. Weighted tasks from the DRACO set are scored from the verdicts.

The 100 published DRACO tasks with their expert rubrics (four dimensions, weighted criteria, penalties for errors), from the MIT-licensed dataset; a copy is in app/data/. A sample of 0 loads all 100; any other number draws a reproducible stratified sample across the ten domains, fixed before any system runs (S6). Replaces the tasks below.
